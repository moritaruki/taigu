# 台語1000 PWA v4

台湾語1,000語＋日常会話300文を「カード・文章・型・クイズ・一覧・進捗」で独学するiPhone向けPWAです。

## v4 の主な機能
- 単語1,000語（初級450 / 中級350 / 上級200）
- 日常会話300文（初級150 / 中級100 / 上級50）
- 文章カテゴリ12種：自己紹介、家族、仕事・学校、数字・時間、食事、買い物、交通、ホテル・旅行、体調、友人・日常、困りごと・依頼、計画・意見
- よく使う「型」24パターン
- 文章カード：台湾語→日本語、日本語→台湾語
- 文章4択クイズ：回答直後に正誤・正解文・臺羅・日本語訳・文型解説を表示
- 単語4択クイズ、定型表現クイズ
- 音声再生
  - 対応単語：教育部《臺灣台語常用詞辭典》の真人音声
  - 非対応単語・文章・型：臺羅から意傳科技「媠聲」で合成する参考音
- 学習記録・お気に入り・復習予定を端末内に保存

## 文章教材について
300文は教育部《臺灣台語常用詞辭典》の語法・用例・臺羅表記を参照しながら、本教材向けに新規作成しています。公式用例の大量転載ではありません。

## iPhoneで使う
GitHub Pages など HTTPS 上で配信し、Safariの共有メニューから「ホーム画面に追加」してください。

## 音声について
教育部真人音声は原音を加工せず利用します。文章・定型表現などの合成音声は学習用の参考で、ネイティブ発音や連読変調の完全な再現を保証するものではありません。詳細は `ATTRIBUTION.md` を参照してください。
