# 台語1000 PWA v2

台湾語の独学用PWA。既存の500語版から更新した版です。

## 主な機能
- 台湾語 **1,000語** を収録
- 初級450語・中級350語・上級200語
- 「我欲〜」「〜佇佗位？」「這是啥物？」など **24の型** を別タブで学習
- 4択クイズ：回答直後に「正解／不正解」・正解・発音・例文を表示
- 台湾語→日本語 / 日本語→台湾語 / 定型表現クイズ
- カテゴリー・難易度フィルター
- お気に入り、習得記録、復習予定
- オフライン対応
- 500語版の学習記録を初回起動時に引き継ぎ

## GitHub Pagesで更新する
現在のリポジトリのルートに、このフォルダのファイルをすべて上書きアップロードして `Commit changes` してください。
GitHub Pages の設定（`main` / `/(root)`）は変更不要です。

## データについて
ChhoeTaigi のライブWebサイトをスクレイピングしていません。
ChhoeTaigiDatabase で公開されている資料を語彙・ローマ字表記の参照元として使用しています。
主な参照資料：
- ChhoeTaigiDatabase / 台灣白話基礎語句 (A Basic Vocabulary for a Beginner in Taiwanese), CC BY-SA 4.0
- ChhoeTaigiDatabase / 台華線頂對照典, CC BY-SA 4.0

日本語訳、初級・中級・上級の分類、学習用例文、型学習の教材部分は本PWA向けに編集しています。
台湾語には地域差や変調があるため、重要語は ChhoeTaigi / 教育部辞典などでも確認してください。

詳しいクレジットは `ATTRIBUTION.md` を参照してください。
