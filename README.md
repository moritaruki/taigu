# 台語1000 PWA v3

台湾語1,000語を「カード・型・クイズ・一覧・進捗」で独学するiPhone向けPWAです。

## v3 の主な機能
- 1,000語（初級450 / 中級350 / 上級200）
- よく使う「型」24パターン
- 回答直後に正誤・正解・発音・例文を表示する4択クイズ
- 単語の発音再生
  - 対応語: 教育部《臺灣台語常用詞辭典》の真人音声
  - 非対応語: 臺羅から意傳科技「媠聲」で合成した参考音
- 「型」の例文を臺羅から合成再生
- 一度取得した音声はService Workerのキャッシュに保存
- 学習記録・お気に入り・復習予定を端末内に保存

## iPhoneで使う
GitHub Pages など HTTPS 上で配信し、Safariの共有メニューから「ホーム画面に追加」してください。

## 音声について
教育部真人音声は原音を加工せず利用します。合成音声は学習用の参考で、ネイティブ発音の保証はありません。詳細は `ATTRIBUTION.md` を参照してください。
