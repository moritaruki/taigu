# 台語2500 PWA v5

TOCFL Band C2相当の台湾華語力を足場に、台湾語を無理なく広げるためのiPhone向けPWAです。

## 学習量
- 台湾語 2,500語
  - 初級 450
  - 中級 750
  - 上級 900
  - 発展 400
- 文章 800文
  - 初級 150
  - 中級 250
  - 上級 250
  - 発展 150
- 定型表現 24パターン

## C2向け「華語ブリッジ」
既存1,000語に加えた1,500語は、台湾華語の既知語から台湾語へ移行しやすいよう「華語：〜」を併記しています。
追加語は iTaigi華台對照典（CC0）を中心に選び、基礎語彙に該当するものは台灣白話基礎語句（CC BY-SA 4.0）とも照合しています。

## 文章学習
既存300文に、予定・条件・理由・説明・抽象的意見を中心とする500文を追加しました。
文章クイズは台湾語→日本語、日本語→台湾語の両方向に対応し、回答後に臺羅・文型解説・音声を表示します。

## 音声
- 対応する既存語：教育部《臺灣台語常用詞辭典》真人音声
- 追加語・文章・型：臺羅から合成する参考音
- 合成音は学習用参考で、地域差・連読変調・自然な韻律を完全に保証するものではありません。

## iPhone
HTTPSで公開し、Safariの共有メニューから「ホーム画面に追加」するとPWAとして利用できます。
