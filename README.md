# 台語500 PWA

## iPhoneで使う
PWAは HTTPS 上で配信すると、Safariの「共有」→「ホーム画面に追加」からアプリのように使えます。

## ファイル
- index.html
- data.js（500語）
- manifest.webmanifest
- sw.js（オフラインキャッシュ）
- icon-192.png / icon-512.png

## 公開方法の例
GitHub Pages / Netlify / Cloudflare Pages などの静的ホスティングに、このフォルダの中身をそのままアップロードしてください。

## 注意
- 学習記録は端末の localStorage に保存。
- 発音はTâi-lô系の学習表記。地域差・変調があるため、重要語は辞書で照合してください。
- ChhoeTaigi の大量取得・転載は行っていません。
